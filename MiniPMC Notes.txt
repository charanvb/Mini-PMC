HTTPS on port 443 — what you need

A certificate and key as PEM files. For a .pfx, run python -m minipmc pfx-to-pem file.pfx --password …. With no certificate, run pip install cryptography, then python -m minipmc make-cert --names "host,fqdn,ip". A self-signed one gives browser warnings until it is trusted on each PC.
Nothing else listening on port 443 on the server.
Re-run the installer once, as Administrator: .\scripts\install-service.ps1 -CertFile <crt> -KeyFile <key> -OpenFirewall. With a certificate the port defaults to 443, and the watchdog probes https.
An inbound TCP 443 rule on the Azure NSG, limited to your office or VPN ranges.
